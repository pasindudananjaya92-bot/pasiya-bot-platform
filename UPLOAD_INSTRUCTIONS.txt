PASIYA MongoDB Search — Upload guide

FILES IN THIS ZIP (must all have content):
1) api/search-users.js     ← REQUIRED (this was missing on GitHub)
2) search.html             ← search page UI
3) package.json            ← mongodb dependency for Vercel
4) SEARCH_SNIPPET.html     ← optional paste into index.html
5) UPLOAD_INSTRUCTIONS.txt
6) README_SEARCH.md

HOW TO UPLOAD TO GITHUB
A) api/search-users.js
   - Open repo → folder "api"
   - Add file → Upload files → select search-users.js
   - Path must be: api/search-users.js  (NOT root)

B) search.html + package.json
   - Repo root → Upload files

C) Commit changes

D) Vercel
   - Env: MONGODB_URI must exist (Production + Preview)
   - Wait for deploy

E) Test
