"No API key found in request" FIX

1) Supabase Dashboard → Project Settings → API
2) Copy "anon" / "publishable" key (NOT secret/service_role)
3) Site → Settings → paste into Supabase anon public key
4) SAVE — must show SAVED OK
5) Same browser → Sign in with Google

Do NOT put the key in public chat.
Hardcoding key in GitHub works but exposes it in repo; Settings/localStorage is enough if you SAVE before login.
