# Contributing to Pasiya Max Platform

Thank you for helping improve this free AI command center.

## How to contribute

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-idea`
3. Make focused changes (prefer small PRs)
4. Test locally by opening `index.html` in a browser
5. Open a Pull Request with a clear description

## Guidelines

- Keep the project **usable without paid plans** when possible
- Do not commit API keys, tokens, or `.env` secrets
- Prefer accessible, mobile-friendly UI
- Document new sections in `README.md` and `docs/`
- Match existing visual style (cyber / command-center)

## Ideas that help

- New free tool links (working URLs only)
- Translations (Sinhala / English)
- Accessibility improvements
- n8n workflow examples (no private tokens)
- Bug fixes and performance

## Code of conduct

Be respectful. No harassment, spam, or malicious code.
