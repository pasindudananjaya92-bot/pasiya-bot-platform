◆ FAQ // VISITOR QUESTIONS

Clear answers so users stay and trust the hub

Is this free?

Yes. The hub is free to open. Some tools need free signups (Groq, n8n, Make, Vercel). We do not charge for access to this site.

Do I need an API key to chat?

No for N8N Public Bot. Yes only if you use BOT CORE with your own free Groq/Gemini key (saved in your browser).

Is my key safe?

BOT CORE keys stay in localStorage on your device. Never paste keys into public group chats or GitHub. Operator secrets stay in n8n/Vercel env — not in the website HTML.

What is Control Bridge?

This site is a middle layer: one cyber UI that routes you to free AI, automation and hosting tools, plus the owner’s connected n8n / Make / Mongo stack.

Something failed — what now?
