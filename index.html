📖 Complete Free Bot Creation Guide

Follow these steps to create a real powerful free bot

Get a Free LLM API Key

Go to console.groq.com → Sign up → Create API Key. This is the fastest free option.

Test Your Bot Here

Paste the API key in the Bot Builder above, set a system prompt, and chat. This confirms everything works.

Create Telegram or Discord Bot

For Telegram: Talk to @BotFather → /newbot → Get token.
For Discord: discord.com/developers → New Application → Bot → Token.

Write Simple Bot Code

Use Python (python-telegram-bot or discord.py) + your free Groq/Gemini key. Many free templates exist on GitHub.

Deploy Free 24/7

Upload code to Replit or Railway. Use free keep-alive methods or free cron services.

Add Memory & Tools (Optional)

Connect free Supabase or Upstash Redis so your bot can remember conversations and become much smarter.
