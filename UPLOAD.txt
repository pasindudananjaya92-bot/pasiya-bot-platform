This is a FULL Next.js project (not a single index.html).

Option A — New Vercel project
1. Unzip
2. vercel / GitHub import this folder
3. npm install is automatic on Vercel
4. Add env vars from .env.example

Option B — Replace pasiya-bot-platform root
1. Backup current static site
2. Upload these files as new root (keep /api if needed)
3. Vercel framework preset: Next.js

Do NOT only overwrite index.html — this is app/ based.
