# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Standards

**Positive:** respectful communication, constructive feedback, focus on what is best for the community.

**Unacceptable:** insults, harassment, doxxing, posting others' private keys, spam, malicious PRs.

## Enforcement

Maintainers may remove comments, lock threads, or block contributors who violate this code.

## Scope

Applies to this repository, issues, pull requests, and related public spaces for the project.
