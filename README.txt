PASIYA AUTONOMOUS AGENT

1. Upload pasiya-autonomous-agent.js to the same GitHub project/folder as index.html.
2. In index.html, add this line before </body>:

<script src="pasiya-autonomous-agent.js"></script>

3. Save/commit both files.
4. Refresh the website.

The JavaScript function expects the existing page to provide:
- #inp
- #apiKey
- add()
- showModal() (optional)
- groq()

This ZIP contains the exact function supplied by the user; no extra agent logic was added.
