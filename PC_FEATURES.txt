PASIYA VIRTUAL PC — feature list (current)

SHELL
- Virtual PC page (desktop simulation in browser)
- Top bar: FULL, WALL, KEYBOARD, AGENT, DASHBOARD
- Start button + nested/mega start menus
- Address / GO / BACK TO PC
- Desktop icon grid
- Task list / system style panels

DESKTOP ICONS (examples)
- Start, Explorer, SysSettings, Recycle, TaskMgr
- Paint, Clock, Sticky, Help, Shortcuts, Notepad
- Files, Calc, Terminal, Browser, Tools, Projects
- Bot Lab, Settings, Cloud IDE, User Search, Feedback
- Replit, GitHub, n8n, Vercel, MongoDB, Supabase

APPS / WINDOWS
- Window-style panels (vwin) open from icons
- Titlebar controls (min/max/close) in later patches
- In-PC browser field

INPUT
- On-screen keyboard (letters, numbers, space, backspace)
- Extra keys row in patches (Esc, Tab, Ctrl, F-keys, arrows…)
- Trackpad zone
- L CLICK / R MENU buttons
- Simulated cursor

CONNECTED / LINKED SERVICES
- User Fuzzy Search → Vercel /api/search-users → MongoDB Atlas
- Feedback page → /api/feedback → MongoDB (if uploaded)
- Webhooks settings: n8n, Make, Pipedream
- Supabase URL/key in Settings (Google login if project live)
- External opens: Replit, GitHub, n8n, Vercel, Mongo, Supabase

LIMITS (honest)
- Not a real OS kernel / not real mouse driver
- OAuth/cloud tools need real browser tabs + live accounts
- Large menu trees can make phone heavier
